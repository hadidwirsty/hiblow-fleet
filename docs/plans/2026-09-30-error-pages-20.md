# Plan: Implementation of Error Pages (401, 403, 404, 500)

## Overview
This plan details the atomic tasks to create consistent, animated error pages across the application using the existing Lottie animations in `/public/animations`.

We will create a reusable `ErrorView` component and implement the standard Next.js error boundaries (`not-found.tsx`, `error.tsx`) as well as custom error routes (`/unauthorized` for 401, `/forbidden` for 403). For the 401 error, we will use `error403.json` as a fallback animation since `error401.json` does not exist yet.

## Tasks

### Task 1: Reusable Error View Component

**Files:**
- Create: `components/ui/error-view.tsx`

**Requirements:**
- **Acceptance Criteria**
  1. Component receives props: `statusCode`, `title`, `description`, `animationPath`, `actionLabel`, `actionHref`, `onAction`.
  2. Renders a centered, responsive layout containing the `LottiePlayer` component.
  3. Displays the status code, title, and descriptive text cleanly.
  4. Renders either a primary action button (using `onAction`) or a Next.js `<Link>` button (using `actionHref`).

- **Functional Requirements**
  1. Must act as the foundational layout for all error pages.
  2. The `LottiePlayer` component receives `src={animationPath}`.

- **Non-Functional Requirements**
  - Fully responsive, centering content on both mobile and desktop screens.
  - Consistent typography using Tailwind CSS (`text-foreground`, `text-muted-foreground`).

- **Test Coverage**
  - None required for this UI-only wrapper component.

**Step 1: Write minimal implementation (GREEN)**
```tsx
import * as React from "react"
import Link from "next/link"
import { Button } from "@/components/ui/button"
import { LottiePlayer } from "@/components/ui/lottie-player"

interface ErrorViewProps {
  statusCode: string
  title: string
  description: string
  animationPath: string
  actionLabel?: string
  actionHref?: string
  onAction?: () => void
}

export function ErrorView({
  statusCode,
  title,
  description,
  animationPath,
  actionLabel = "Kembali ke Beranda",
  actionHref = "/",
  onAction,
}: ErrorViewProps) {
  return (
    <div className="flex min-h-[80vh] flex-col items-center justify-center p-4 text-center">
      <div className="mb-6 h-64 w-64 sm:h-80 sm:w-80">
        <LottiePlayer src={animationPath} loop autoplay />
      </div>
      <h1 className="text-4xl font-bold tracking-tight text-foreground sm:text-5xl">
        {statusCode}
      </h1>
      <h2 className="mt-4 text-xl font-semibold text-foreground sm:text-2xl">
        {title}
      </h2>
      <p className="mt-2 max-w-md text-sm text-muted-foreground sm:text-base">
        {description}
      </p>
      <div className="mt-8">
        {onAction ? (
          <Button size="lg" onClick={onAction}>
            {actionLabel}
          </Button>
        ) : (
          <Button size="lg" asChild>
            <Link href={actionHref}>{actionLabel}</Link>
          </Button>
        )}
      </div>
    </div>
  )
}
```

### Task 3: Implement Global Error Boundary (500)

**Files:**
- Create/Modify: `app/error.tsx`

**Requirements:**
- **Acceptance Criteria**
  1. Uses the `"use client"` directive (required by Next.js error boundaries).
  2. Receives `error` and `reset` props.
  3. Uses `statusCode="500"`, `title="Terjadi Kesalahan Internal"`, and `animationPath="/animations/error500.json"`.
  4. Provides a "Coba Lagi" action calling the `reset` function.

- **Functional Requirements**
  1. Catches unhandled runtime errors in React components.

**Step 1: Write minimal implementation (GREEN)**
```tsx
"use client"

import { useEffect } from "react"
import { ErrorView } from "@/components/ui/error-view"

export default function GlobalError({
  error,
  reset,
}: {
  error: Error & { digest?: string }
  reset: () => void
}) {
  useEffect(() => {
    console.error("Global boundary caught:", error)
  }, [error])

  return (
    <ErrorView
      statusCode="500"
      title="Terjadi Kesalahan Internal"
      description="Maaf, sistem sedang mengalami kendala. Silakan coba beberapa saat lagi."
      animationPath="/animations/error500.json"
      actionLabel="Coba Lagi"
      onAction={() => reset()}
    />
  )
}
```
