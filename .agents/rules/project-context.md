## 1. Project Overview & Identity

- **Project Name:** `hiblow-fleet`
- **Domain:** Fleet & Financial Management Application for Bulk Cement Transport (Truck HI-Blow).
- **Business Background:** Replaces manual spreadsheet workflows (`PERHITUNGAN HIBLOW HW Trans.xlsx`) used by HW Trans to track operational logs, expenses, driver stipends (*sangu*), incentives, and partner profit sharing (*bagi hasil*).
- **Core Assets & Scope:**
  - **Fleet Scale:** Fixed 2 units — `W8187UA` and `H8133OF` (static fleet, no dynamic add/delete required).
  - **Multi-tenant / Multi-user:** Role-based web application with server-side authentication (Admin, Operator/Input Staff, Partner/Viewer).
  - **Data Integrity Rule:** Historical formulas and calculation behaviors from the original spreadsheet are canonical; formulas must not be redesigned arbitrarily.

## 3. Authoritative Domain Model & Formulas (Excel Ground Truth)

The original Excel workbook `PERHITUNGAN HIBLOW HW Trans.xlsx` contains 8 primary sheets:
1. `SI Tarif` (Semen Indonesia route rate references)
2. `SBI Tarif` (Semen Bima route rate references)
3. `Indocement Grobogan Tarif` (Indocement route rate references)
4. `Masuk W8187UA` (Trip income log for W8187UA)
5. `Keluar W8187UA` (Expense log for W8187UA)
6. `Masuk H8133OF` (Trip income log for H8133OF)
7. `Keluar H8133OF` (Expense log for H8133OF)
8. `Bagi Hasil` (Period-based partner profit-sharing calculation)

### 3.1 Entity: RateReference (`rates` / `rate_references`)
- **Source:** Sheet `SI Tarif`, `SBI Tarif`, `Indocement Grobogan Tarif`
- **Purpose:** Lookup table for auto-filling rates, driver stipends, and standard tonnages when dispatching a trip.
- **Fields:**
  - `id`: UUID (Primary Key)
  - `client_name`: String (`SI`, `SBI`, `Indocement Grobogan`)
  - `city`: String (e.g., `REMBANG`, `CEPU`, `PATI`, `SEMARANG`, `UNGARAN`)
  - `destination`: String (e.g., `ARIES PUTRA BETON`, `PRY TOL SEMARANG (SAYUNG)`, `KH BETON`)
  - `rate_per_ton`: Numeric/Decimal (Tarif dasar per ton)
  - `standard_tonnage`: Numeric/Decimal (Default 31.0 ton)
  - `sangu_percentage`: Numeric/Decimal (e.g., 52% or route-specific ratio)
  - `additional_tonnage_rate`: Numeric/Decimal (e.g., Rp 25.000 / ton)
  - `created_at`, `updated_at`: Timestamps

### 3.2 Entity: Trip (`trips`)
- **Source:** Sheet `Masuk W8187UA`, `Masuk H8133OF`
- **Purpose:** Log of delivery orders (DO) and revenue per truck.
- **Fields & Mathematical Formulas:**
  - `id`: UUID
  - `truck_id`: String / Enum (`W8187UA`, `H8133OF`)
  - `order_number`: Integer / String (Nomor Urut Order)
  - `order_date`: Date (`TANGGAL ORDER`)
  - `unloading_date`: Date / Nullable (`TANGGAL BONGKAR`)
  - `destination_city`: String
  - `destination_name`: String
  - `rate_per_ton`: Numeric/Decimal (`TARIF`)
  - `loaded_tonnage`: Numeric/Decimal (`TONASE MUAT`)
  - `unloaded_tonnage`: Numeric/Decimal (`TONASE BONGKAR`)
  - **`omset` (Revenue):**
    $$\text{Omset} = \text{rate\_per\_ton} \times \text{unloaded\_tonnage}$$
  - **`sangu` (Driver Allowance):**
    $$\text{sangu\_base\_tonnage} = \min(\text{unloaded\_tonnage}, 31.0)$$
    $$\text{sangu} = \operatorname{ROUND}(\text{sangu\_base\_tonnage} \times \text{sangu\_percentage} \times \text{rate\_per\_ton}, -3)$$
    *(Rounded to nearest thousand)*
  - **Deductions & 3rd Party Fees:**
    - `tax_1pct`: Optional/Client-specific (`omset * 0.01`)
    - `pot_2pct_lju`, `uj_5pct_grb`: Route/client specific deductions
    - `third_party_fee`: Third-party DO fees (e.g., `Mas Mawan / CV. Satria Perwira`, `Mbah Man / SILOG`)
    - `third_party_paid_status`: String / Boolean (e.g., `Sudah dibayar [date] [x]rit`)
  - **Incentives & Allowances:**
    - `incentive_rate`: Numeric (e.g., Rp 35.000 per rit)
    - `incentive_paid`: Numeric (`rit_count * incentive_rate`)
    - `meal_allowance` (*Bantuan Uang Makan*)
    - `savings` (*Tabungan*)
    - `claim_driver`, `claim`: Claim deductions for shrinkage exceeding tolerance (0.3%)
  - **`net_profit` (Trip Profit):**
    $$\text{Profit} = \text{Omset} - \text{Sangu} - \text{Incentive Paid} - \text{Third Party Fee} - \text{Taxes/Other Direct Trip Deductions}$$
  - `notes`: Text (Catatan detail)

### 3.3 Entity: Expense (`expenses`)
- **Source:** Sheet `Keluar W8187UA`, `Keluar H8133OF`
- **Purpose:** Operational and capital expenditures recorded per truck.
- **Fields:**
  - `id`: UUID
  - `truck_id`: String / Enum (`W8187UA`, `H8133OF`)
  - `expense_date`: Date
  - `category`: String (e.g., `Servis/Mekanik`, `Onderdil/Perlengkapan`, `GPS`, `DP/Cicilan Truk`, `BBM`, `Administrasi`)
  - `description`: Text (e.g., `Jasa Cek Truk Mas Mawan & Pak Rokhim`, `Selang Gajah 5m`, `GPS Idtrack Truk 1 Tahun`)
  - `amount`: Numeric/Decimal
  - `admin_fee`: Numeric/Decimal (Biaya admin transfer bank)
  - `location`: String (e.g., `Tuban`, `Kudus`, `Semarang`)
  - `repair_notes`: Text

### 3.4 Entity: ProfitSharingPeriod & Shares (`profit_sharing_periods`, `profit_shares`)
- **Source:** Sheet `Bagi Hasil`
- **Purpose:** Calculation of net profit distribution over agreed date ranges (e.g., 25 Jul - 31 Aug 2025, 1 - 30 Sep 2025).
- **Core Mechanics:**
  1. `period_start`, `period_end`: Date range.
  2. `total_income`: Sum of trip profits (or total net fleet revenue) within the period.
  3. `total_expenses`: Sum of operational expenses (`amount + admin_fee`) within the period.
  4. `gross_balance`: $\text{total\_income} - \text{total\_expenses}$.
  5. `manager_commission` (*Komisi Hafidz*): Typically 5% of `gross_balance` (or agreed flat sum):
     $$\text{commission} = \text{gross\_balance} \times 0.05$$
  6. `distributable_profit`: $\text{gross\_balance} - \text{manager\_commission}$.
  7. **Dynamic Partner Shares (`profit_shares`):**
     Investor shares are calculated dynamically per period based on investment capital over fleet valuation:
     $$\text{share\_ratio} = \frac{\text{partner\_capital}}{\text{total\_fleet\_valuation}}$$
     *(e.g., 50.000.000 / 580.000.000 = 8.620689%, 75.000.000 / 580.000.000 = 12.931034%, 4.000.000 / 580.000.000 = 0.689655%)*
     $$\text{partner\_payout} = \text{share\_ratio} \times \text{distributable\_profit}$$
  8. **Manager Profit Share (`profit_hafidz`):**
     $$\text{manager\_profit} = \text{distributable\_profit} - \sum \text{partner\_payouts}$$
     $$\text{total\_manager\_take\_home} = \text{manager\_profit} + \text{manager\_commission}$$

## 6. Coding Standards & Governance Rules

### 6.1 Language Policy
- **Interaction & Dialogue:** All conversation with the user (status updates, questions, checklists, summaries) **MUST be in Bahasa Indonesia**.
- **Code & Technical Artifacts:** Code, variables, SQL schema, commit messages, API specs, and technical documentation **MUST be in English**.

### 6.2 The Supremacy Hierarchy (`technical-constitution`)
1. **Security:** OWASP compliance, deny-by-default, sanitize inputs, never leak secret credentials or internal stack traces.
2. **Testability-First:** Business calculation logic (Omset, Sangu, Profit, Bagi Hasil) **must be pure functions** without embedded database calls. Storage must be behind Go interfaces (`Repository`).
3. **Error Handling:** Explicit errors only. All HTTP error responses must use a standard JSON envelope:
   ```json
   {
     "status": "error",
     "code": "VALIDATION_FAILED",
     "message": "Human readable message",
     "correlationId": "uuid-v4",
     "details": {}
   }
   ```
4. **Clean Code:** Adhere strictly to `.agents/skills/clean-code-standards/SKILL.md` (import hierarchy: runtime $\to$ third-party $\to$ internal $\to$ types).
5. **No Secret Leaks:** Do not log passwords, keys, or tokens. Use `.env.example` templates for configuration reference.
